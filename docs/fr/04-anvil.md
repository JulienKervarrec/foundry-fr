# 4. Anvil et environnement local

Anvil fournit un nœud Ethereum local rapide et peut forker un réseau distant. Il permet de reproduire un état de chaîne pour développer et inspecter des scénarios.

Un fork local n’est pas une preuve de comportement de production : les différences d’horloge, de RPC, de liquidité et de configuration doivent être documentées.
