# 5. Chisel, intégration et limites

Chisel est un REPL Solidity utile pour explorer rapidement des expressions. Forge LSP relie l’éditeur aux conventions du projet, notamment foundry.toml, les remappings et la version EVM.

Ce parcours couvre l’outillage visible dans le dépôt, mais ne remplace pas une compilation, un test, un audit ou une vérification de release. Aucune installation, compilation ou exécution n’a été réalisée ici.
