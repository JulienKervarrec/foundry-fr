# 1. Vue d’ensemble de Foundry

Foundry est une boîte à outils Ethereum en Rust. Le monorepo regroupe Forge pour les contrats, Cast pour le RPC, Anvil pour un nœud local et Chisel pour l’exploration Solidity.

La séparation en crates et commandes permet de passer du code au diagnostic sans changer d’écosystème.
